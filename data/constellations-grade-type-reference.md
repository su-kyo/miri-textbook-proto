# 미리교과서 별자리 등급·타입 분류표

## 기준

- 이 문서는 미리교과서 별자리 수집 시스템에서 사용할 별자리 등급과 타입 분류표입니다.
- 홈/출석판에서는 별자리 구조도를 노출하지 않고, `requiredLight` 기준의 게이지로만 진행도를 표현합니다.
- 카드/도감에서는 그림용 일러스트와 별자리 구조도 완성본을 겹쳐 표현합니다.
- `grade`는 서비스 수집 난이도입니다.
- `requiredLight`는 카드 획득에 필요한 별빛 수입니다.
- `typeKo`는 일러스트 및 카드 색상 구분 기준입니다.
- 사물형에는 추상형을 포함합니다.
- 별자리 구조도 속 실제 별 개수와 `requiredLight`는 서로 다른 개념입니다.

## 타입 코드

| typeKo | typeCode | 설명 |
|---|---|---|
| 인물형 | character | 인물, 신화 인물, 사람형 존재 |

| 사물형 | object | 사물, 도구, 추상형, 지형, 배/항해 관련 사물 |
