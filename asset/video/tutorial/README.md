# 글자 맞추기 튜토리얼 가이드 영상

학습 첫 진입 시 노출되는 조작법 안내 오버레이에 들어가는 영상입니다.
글자·텍스트 없이 스켈레톤 도형만 사용하므로 실제 문제의 정답을 노출하지 않습니다.

## 파일 매핑

| 파일 | 화면 | 테마 | 루프 길이 | 용량 |
| --- | --- | --- | --- | --- |
| `letter-swap-light.mp4` | 1~2학년 (타일 순서 바꾸기) | 라이트 | 4.2초 | 약 24KB |
| `letter-swap-dark.mp4` | 1~2학년 (타일 순서 바꾸기) | 다크 | 4.2초 | 약 21KB |
| `letter-fill-light.mp4` | 3~6학년 공용 (빈칸에 끌어다 놓기) | 라이트 | 5.6초 | 약 51KB |
| `letter-fill-dark.mp4` | 3~6학년 공용 (빈칸에 끌어다 놓기) | 다크 | 5.6초 | 약 43KB |

- 3~4학년과 5~6학년은 동일한 `letter-fill-*` 영상을 사용합니다.
- 공통 스펙: 560×360px (표시 크기 280×180의 @2x 레티나), 30fps, H.264(yuv420p), 무음.

## 사용 방법

```html
<video src="letter-fill-light.mp4" autoplay muted loop playsinline></video>
```

- `muted`가 없으면 모바일 브라우저에서 자동재생이 차단됩니다. `playsinline`이 없으면 iOS에서 전체화면으로 열립니다.
- 시작·끝 프레임이 동일하게 설계되어 `loop` 재생 시 이음새가 보이지 않습니다.
- 영상 자체는 각진 사각형입니다. 라운딩(14px)은 감싸는 컨테이너에서 `border-radius + overflow: hidden`으로 처리하세요.
- 배경색이 테마별로 구워져 있으므로 다크모드 전환 시 `src`를 `-dark` 파일로 교체해야 합니다.
- 모션 최소화 설정(`prefers-reduced-motion`) 사용자는 자동재생 대신 성공 장면(전체 길이의 70% 지점)에 멈춰 두는 것을 권장합니다.
